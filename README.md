# Prasad Sudhir Thorat — Portfolio

Personal portfolio website of **Prasad Sudhir Thorat**, Integrated B.Tech CSE student at Sanjivani University, Kopargaon, focused on cybersecurity, cloud infrastructure and applied AI.

**Live site:** https://prasadthorat25uid-arch.github.io/portfolio_prasad_29/

## Features
- Terminal-style boot sequence with scramble text effect
- Interactive particle-network background and custom cursor
- 3D tilt cards, scroll reveal animations, responsive layout
- Sections: About, Skills, Experience, Certifications, Events, Contact
- Downloadable resume

## Project structure
```
├── index.html                      # Main site (HTML + CSS + JS in one file)
├── profile.jpg                     # Profile photo
├── RESUME.jpeg                     # Resume (download link)
├── googled50e57dfcd6b0c22.html     # Google Search Console verification (do not delete)
├── robots.txt                      # Crawler rules + sitemap location
├── sitemap.xml                     # Sitemap for Google
└── README.md                       # This file
```

## Google Search Console / SEO
- Ownership verified via the HTML file method (`googled50e57dfcd6b0c22.html`). Keep this file in the repo root or verification will lapse.
- `index.html` includes meta description, canonical URL, Open Graph/Twitter tags and JSON-LD `Person` schema.
- `robots.txt` and `sitemap.xml` are provided for crawling and indexing.

## Run locally
Open `index.html` in a browser, or serve the folder:
```
python3 -m http.server 8000
```

## Deploy (GitHub Pages)
Repo → Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / root.
